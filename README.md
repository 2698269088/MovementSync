## Quick Start

1. **Download**  
   Get the latest version from [Releases](https://github.com/huangdihd/MovementSync/releases):  
   `MovementSync-[version].jar`

2. **Copy** it to your plugin directory.

3. **Launch** [xinbot](https://github.com/huangdihd/xinbot).

---

## Commands

| Command   | Description |
|-----------|-------------|
| `whereami` | Shows the server and current coordinates of the bot |
| `block`    | Returns the block at a specific coordinate |
| `jump`     | Makes the bot jump |
| `look`     | Makes the bot look at a specific coordinate |
| `walk`     | Makes the bot walk |
